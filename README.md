# 🌐 Kittisak Tantratorn — Personal Portfolio

> **Live Site:** [pesonal-web-cyan.vercel.app](https://pesonal-web-cyan.vercel.app)

A modern, dark-themed personal portfolio website built with **Next.js 16** and **Framer Motion**, showcasing my work in GIS & Remote Sensing, AI Engineering, and IoT systems.

## ✨ Features

- **Animated Hero Section** — Smooth fade-in entrance with role description
- **Orbital Photo Gallery** — Floating, rotating image orbit in the About section
- **Tabbed Portfolio** — Switch between Projects, Certificates, and Experience
- **Interactive Project Cards** — 3D tilt effect on hover with Framer Motion
- **Certificate Lightbox** — Click-to-expand certificate viewer
- **Accordion Experience** — Animated expandable work experience cards
- **Magnetic Buttons** — Cursor-following magnetic interaction
- **Spotlight Background** — Dynamic mouse-tracking spotlight effect
- **Fully Responsive** — Mobile-first design across all breakpoints

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/A-Phrom-A/pesonal_web.git
cd pesonal_web
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
